# Site Institucional IACRA
Site público do Instituto de Arte Cristã Raphael Augusto. Projeto separado da plataforma IACRA.

Para prévia no Cloud Run: `gcloud run deploy site-iacra-preview-20261114 --source . --project=e-a-v-r-a --region=southamerica-east1 --allow-unauthenticated --port=8080`

**Atenção:** o domínio principal continua associado à plataforma. Não altere DNS ou a plataforma sem validar a migração dos links existentes.
